# Photobook-app

Mobile application for a freelance client engagement — a booking and
content platform connecting creatives with clients. Built end to end as
the sole developer, covering UI/UX, booking flow, and payments.

## Features

- Creative profile browsing and portfolio display
- Booking flow with calendar-based scheduling
- Google sign-in and phone/OTP authentication
- In-app payments

## Stack

Flutter, Dart, `provider` for state management, `table_calendar` for
scheduling, Google Sign-In

## Status

In active development as an ongoing freelance client engagement.
